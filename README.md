
Travel Unbounded – Full Stack Travel Website:
Develop a responsive travel company website using Next.js, showcasing India and international destination packages with an About and Contact/Enquiry page. The project includes a booking enquiry form with client/server-side validation, MongoDB database integration, API development using Next.js API routes, and deployment on Vercel. The focus is on reusable components, responsive UI, clean code, secure environment variables, and a fully functional enquiry-to-database workflow.
